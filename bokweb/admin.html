Admin token · ტოკენი

The token is a master key: printed when the server starts and saved in data/secret.txt. On the login screen choose “Sign in with admin token instead” — it works even if you forget the password.

Forgot everything? Stop the server, delete data/admin-login.json, start again — the login resets to admin / admin123.

Made a text mistake and saved it? The previous version of your texts is kept in data/site-content-prev.js.
