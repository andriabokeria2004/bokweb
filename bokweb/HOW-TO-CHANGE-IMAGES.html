How to change images / როგორ შევცვალო სურათები

Every picture on the site is now a normal file inside the images folder, sorted by section. Below is every image slot with a live preview of the current file.

New — Admin panel: open admin.html in Chrome for a visual panel that replaces every image and video for you (including the phone copies) and lets you hide, add or delete sections — no file renaming needed.
ახალი — ადმინ პანელი: გახსენით admin.html Chrome-ში — ვიზუალური პანელი ყველა სურათის, ვიდეოსა და სექციის სამართავად.
The one rule: to change any picture, just overwrite the file with your own image, keeping the same file name. You never need to touch the code.
ერთი წესი: სურათის შესაცვლელად უბრალოდ ჩაანაცვლეთ ფაილი თქვენი სურათით — იგივე სახელით. კოდში შესვლა არ გჭირდებათ.
Extras: spare/unused files live in images/_extra (including your ad video “BokWeb Ad - Modern.mp4”) — nothing on the site uses that folder, so it's safe to keep or delete.
Plan videos (optional): drop basic.mp4, pro.mp4, proplus.mp4 into the videos folder to add video to the Prices page hero — until then the hero images above are shown.
Advanced: if you ever want a different file name or a YouTube link instead, the paths sit in clearly-marked blocks: portfolio → script.js (PROJ), services → service.js (SVC_IMAGES), prices → prices.js, feature & logo slots → marked with <!-- ═══ IMAGE ═══ --> comments in the HTML.
